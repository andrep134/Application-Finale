# Refonte complète de l'application Android de l'Église Évangélique Baptiste Bethesda

Ce dossier décrit la nouvelle identité visuelle, la navigation et les écrans Material 3 à implémenter dans l'application mobile afin qu'elle soit parfaitement alignée avec le site officiel de l'EEBB.

- `ui_redesign.md` : directives détaillées pour chaque écran et section.
- `navigation_flow.md` : architecture d'information, navigation principale et transitions.
- `design_tokens.json` : jetons de design (couleurs, arrondis, espacements, ombres, typographies) à intégrer dans le thème Material You.
- `component_states.md` : micro-interactions, états de chargement et d'erreur, ainsi que les effets ripple requis.

Ces documents servent de référence pour implémenter un design premium, harmonieux et fluide répondant à toutes les contraintes fournies.
